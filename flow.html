ご相談後の流れ

原稿を、お預けいただくだけ。

この資料をお読みいただいたあと、ご相談から契約、作品のお預かり、配信開始、お振込まで、どのように進むかをまとめました。オンラインでのご説明をご希望の方も、資料だけご覧になった方も、流れは同じです。配信準備は約一〜二週間、その後は書店ごとに順次配信を開始します。

其の一

ご相談・質疑応答

まずはお気軽にご連絡ください。オンラインでのお打ち合わせは、予約ページからご都合のよい枠をお選びいただけます（30分・Google Meet）。難しい場合は、テキストでの質疑応答でも構いません。カメラ・マイクなし、音声のみでのご参加で結構です。ご予約はペンネーム／サークル名で構いません（本名をお書きいただくのは契約書だけです）。

作家さま：ご相談
其の二

専用の窓口をご用意

Discord の ID を教えていただき、作家さま専用の窓口（チャンネル）をご用意します。契約後の作品のやり取り・データのお渡し・進捗のご報告は、すべてこの窓口で行います。

作家さま：Discord ID を共有
其の三

契約書のご送付・ご署名

マネーフォワードの電子契約で、契約書（配信代行の業務委託契約）をメールでお送りします。押印も郵送も不要。スマートフォンからでも数分で完了します。契約書の料率が、ご説明やメッセージでお伝えした料率と違っていたら、ご署名の前に必ずお知らせください。一致させてからご署名いただきます。操作がお分かりにならない場合も、ご遠慮なくご連絡ください。手順をご案内します。

好色堂：契約書を送付 → 作家さま：電子署名
其の四

原稿データをお預かり

本編データ（CLIP・PSD・JPG・PDF など。JPGをページ順にZIPでまとめていただく形で十分です）と表紙用の素材を、専用の窓口・大容量便・Googleドライブの共有フォルダのいずれかでお渡しください。形式はお手元のままで結構です。奥付に載せる X のIDは配信後に変更できませんので、長くお使いのものをお知らせください。書影（書店に並ぶ表紙まわりの画像）は好色堂が制作します。

作家さま：データをお渡し
其の五

表紙・電子化・入稿

表紙の制作、電子書籍（EPUB）化、書誌情報の作成、白抜き・モザイクの処理、各書店への入稿・審査対応まで、すべてこちらで仕上げます（配信準備に約一〜二週間。その後は書店ごとの審査が通った順に配信が始まります。全書店の一斉公開日や、ご契約から初公開までの総日数はお約束できません）。

好色堂：制作・入稿・審査対応
其の六

配信開始・お支払い

準備の整った書店から順に配信を開始し、配信が始まりましたら専用の窓口でお知らせします。あわせて、ご自身でも書店で作品名を検索してご確認ください。日が経っても見当たらない場合は、すぐにお知らせください。売上（総額）は月末に速報値を共有し、四半期ごと（年4回）にお支払い。初回のお振込は配信開始からおよそ6ヶ月後が目安です。振込手数料は好色堂が負担します。

好色堂：配信・売上共有・お振込
作家さまにお願いするのは、実質「ご署名」と「データのお渡し」の二つだけ。

制作・書店対応・売上の管理は、すべて好色堂が引き受けます。お預けいただく作品が増えるほど、月々の還元は安定して積み上がりますので、棚に眠っている既刊もどうぞまとめてお声がけください。
